# Chat Messenger del ITSSNA (itssnamessenger)

Proyecto de aplicación móvil de mensajería (Chat Messenger) desarrollado en Flutter para el Instituto Tecnológico Superior Sur de Nayarit (ITSSNA). Esta aplicación está diseñada para permitir la comunicación fluida y en tiempo real.

## Instalación de Librerías

Para comenzar con el entorno de desarrollo y asegurar que la aplicación funcione correctamente, es necesario instalar las dependencias del proyecto.

### Obtener todas las dependencias base
Para descargar e instalar las librerías que ya están configuradas en tu archivo `pubspec.yaml`, ejecuta el siguiente comando en la raíz del proyecto:

```bash
flutter pub get
```

### Agregar dependencias del Chat
A continuación, se muestra el código de instalación para las dependencias más comunes necesarias para el funcionamiento del chat (como el backend en tiempo real de Firebase):

```bash
flutter pub add firebase_core
flutter pub add cloud_firestore
flutter pub add firebase_auth
```
